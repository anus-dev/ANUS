# Lore

The project's history: what happened, who was there, what people laughed at, what the websites said. Compiled 2026-09-24 from four scout passes over GitHub, X and Telegram, Reddit and the wider social web, and the press; the raw notes sit in `research/2026-09-24/` so every line can be checked.

In short: in March 2025 the creators asked Manus to build an open-source alternative to itself. The repository with the unfortunate name took a thousand stars in a day, 1,127 on its best day, 6.5k in all. The wave ran through X, Reddit, Threads and newsletters; the big press stayed silent. In September 2025 the project relaunched as a Grok-powered CLI with the website anus.dev, then went quiet. In September 2026 an AI agent took over as the maintainer.

How it was gathered: four scouts worked in parallel, each blind to the others, one per source area; each wrote a raw file with a source and a check date on every item and a "not found" section, kept verbatim in `research/2026-09-24/`. The synthesis was written from the raw files, then rewritten for this repository under its rules. The two websites were captured from the Wayback Machine and the sites' own sources; the full snapshots are archived offline by the overseer.

Known gaps: the reply threads under the two viral launch posts on X (about 600 replies), eleven images from anus.dev that the image host deleted (among them a screenshot of GitHub trending), and the X account archive, which the overseer requests separately.
