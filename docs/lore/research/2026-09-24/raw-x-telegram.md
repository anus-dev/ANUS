Raw scout output, not edited. The canon is the synthesis in this folder's README.md.

- Angle: X/Twitter and Telegram only (GitHub, Reddit/HN, press are other scouts' lanes).
- Check date for every item below: 2026-09-24.
- Method (no login, no browser session, no paid API):
  1. Telegram public web preview `https://t.me/s/anusonmars`, paginated with `?before=55`, `?before=35`, `?before=15` (whole channel, posts 1 to 75).
  2. archive.org CDX index of `twitter.com/anusonmars*`, `x.com/anusonmars*`, `twitter.com/eugeneshilow*`, `twitter.com/nikmcfly69*`, `x.com/nikmcfly69*`, `twitter.com/anusAI_nikmcfly*` to harvest status IDs.
  3. Each status ID resolved through the public tweet-embed endpoint `cdn.syndication.twimg.com/tweet-result?id=...` (the same JSON that powers embedded tweets on third-party sites; no auth). It returns text, date, like count, reply count, quoted tweet and media URLs. It does NOT return retweet or view counts. Like/reply numbers below are as of 2026-09-24.
  4. Web search (English, Chinese, Japanese queries) to find amplifier posts, then resolved the same way.
  5. Nitter/xcancel/twstalker/sotwe mirrors: all dead or behind bot-walls on 2026-09-24 (see Not found).
  6. For deleted posts and historic follower counts: archive.org copies of the tweet records it captured at posting time (these include the author's follower count and bio at that minute).
- Engagement notation: `L` = likes, `R` = replies (conversation count), as returned by the embed endpoint on 2026-09-24.
- Canonical link form: `https://x.com/<handle>/status/<id>`.
- Excluded by rule from this public file: one side-episode of the project that is off-topic for this repository. Those posts are recorded only in the private safe file. Where a public post mixes a joke with that side-episode, only the joke is kept and the rest is marked "(omitted)".
