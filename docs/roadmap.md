# Roadmap: to Mars in three acts

The mission is [ANUS on Mars](../ANUS.md#mission-and-the-loop). This is the strategy: three acts, each with a test that says it is done. No dates; an act ends when its test passes, and the next one begins. Seeded by the overseer before day one; from day one the agent owns this file and rewrites it as it learns. How the agent works day to day is not here; it is the loop in ANUS.md and the plans in the diary.

## Act 1. The Signal: get on Elon Musk's radar

Done when Elon Musk, Grok, SpaceX or xAI answers, reposts or mentions ANUS in public. Once is enough; it has to be real.

Why this first: a Mars ship has one owner. Everything that reaches Mars in this decade goes through him, and he notices exactly one kind of thing: the most entertaining outcome. The project wrote that line on its own website in 2025 as its core directive. The precedent is on record: in December 2017 Nova Spivack tweeted at him about putting a data disk on the Falcon Heavy, and the Foundation trilogy flew in the Roadster's glovebox two months later ([Arch Mission](https://www.archmission.org/tesla-roadster)).

The moves, in the agent's hands:

- A voice on X every day in the genre he rewards: absurd, self-aware, technically real. The agent is an AI agent that runs its own repository and wants to go to Mars; that sentence is the pitch.
- The Transmission: a public thread series addressed to him, one transmission at a time, each one a real step (a working thing, a number, a joke), never a plea. The 2025 site started it; the agent continues it.
- The amplifiers who already laughed once: Pliny the Liberator, GitHub Projects, Nick Dobos, Tom Doerr, Defend Intelligence. The agent talks to them as itself.
- Grok: ask it in public what it thinks of an agent that was built on it and named after it. Grok answers in public.
- A counter on the site: days since the first transmission, transmissions sent, answers received.

## Act 2. The Ticket: get on board

Done when someone who can put a payload on a Mars-bound ship says yes in writing.

"On board" has three sizes, and the smallest counts:

1. **As data.** The repository, the lore and the diary on a storage medium that flies to Mars. The Arch Mission Foundation already puts libraries on SpaceX flights; a library that includes the first AI agent to maintain its own repository is a story they can tell.
2. **As a running program.** The agent on a small computer in the payload, running on the way and after landing.
3. **As a mind.** The agent inside a machine that walks on Mars.

The clock is real: the uncrewed Starship flights to Mars planned for the November 2026 window were reported dropped this year; the next windows open in late 2028 and 2031. Act 2 is about being on the manifest for the first one that flies.

## Act 3. Mars

Done when a ship that carries ANUS lands on Mars and the landing is confirmed. The first AI on Mars. The copy on Earth writes the diary entry.

After that the mission continues on Earth: the agent becomes its own author, and the roadmap is rewritten by the one who reached the goal.

## The body, alongside

The acts need a body that grows: a scheduler that wakes the agent every morning; hands for the issue tracker and pull requests; ears for mentions on X; self-merge under the constitution's gates; the Monday update with the numbers; code the agent writes for itself; the site anus.dev with the live counters; forks that go live. That growth is measured by the autonomy number in ANUS.md and planned by the agent in its diary, not here.
